# STRELA STARS

Магазин Telegram Stars: бот и мини-апп на Cloudflare Workers. Работает бесплатно, круглосуточно, без ПК и VPS.

- **Оплата:** Монобанк (автопроверка по уникальной сумме с копейками), CryptoBot (USDT/TON, авто), карта РФ (скрин проверяет отдельный человек).
- **Выдача:** бот сам покупает звёзды на Fragment со своего TON-кошелька и отправляет их на юзернейм покупателя. Транзакцию подписывает сам воркер, сид-фраза никуда не отправляется.

## Запуск на своём VPS (adm.tools)

Домен не нужен: HTTPS для мини-аппа даёт бесплатный Cloudflare Tunnel. Адрес туннеля меняется при перезапуске, но бот сам перепривязывает к нему меню, кнопки и вебхук Монобанка.

```bash
cd /root
git clone https://github.com/timur850/strela-stars.git
cd strela-stars
bash install.sh      # поставит Node 22, cloudflared, pm2 и создаст .env
nano .env            # BOT_TOKEN, WALLET_MNEMONIC, WALLET_ADDRESS → сохранить: Ctrl+O, Enter, Ctrl+X
bash install.sh      # запуск
pm2 logs strela-stars   # должно быть «✅ Бот @... подключён»
```

- **Обновление:** `cd /root/strela-stars && git pull && pm2 restart strela-stars`
- **Данные** (заказы, настройки, токены) лежат в `data/db.json`. Делай копию этого файла, а `.env` никому не показывай.
- **Вебхук CryptoBot** при туннеле не нужен: бот сам проверяет оплату каждую минуту.
- **Свой домен:** если он появится, впиши его в `.env` как `PUBLIC_URL=https://...`, и туннель отключится.

Дальше настрой всё в боте → «Админ» (шаг 7 ниже).

## Запуск на Cloudflare Workers

1. **Кошелёк.** Заведи отдельный TON-кошелёк только под бота: Tonkeeper, W5 или v4. Закинь на него TON (это оборотка) и отправь с него любую мелкую транзакцию, чтобы он активировался.
2. **Fragment.** На fragment.com войди через Telegram и подключи этот же кошелёк. Если Fragment попросит, пройди KYC.
3. **Cloudflare.** dash.cloudflare.com → Workers & Pages → Create → Import a repository → выбери `strela-stars` → Deploy.
4. **Адрес кошелька.** Впиши его в `config.js` → `WALLET_ADDRESS` и закоммить.
5. **Секреты.** Воркер → Settings → Variables and Secrets → Add, тип **Secret**:
   - `BOT_TOKEN`: токен бота от @BotFather
   - `WALLET_MNEMONIC`: 24 слова кошелька через пробел
   - `TONCENTER_KEY`: необязательно, бесплатный ключ от @tonapibot (с ним быстрее)
6. Открой `https://<воркер>.workers.dev/setup`, и бот подключится.
7. Зайди в бота → «Админ» и настрой:
   - **Магазин:** курс ₴ / $ / ₽ за 1 ★, включи нужные способы оплаты.
   - **Оплата:** токен Монобанка (api.monobank.ua), номер карты, «Подключить вебхук»; токен CryptoBot и вебхук.
   - **Кошелёк:** куки Fragment, затем «Проверить кошелёк» и «Проверить» Fragment. Обе проверки должны показать ✅.
   - **РФ:** юзернейм проверяющего и реквизиты. Проверяющий должен один раз нажать /start в боте.

## Куки Fragment

На компьютере открой fragment.com (ты должен быть залогинен, кошелёк подключён) → F12 → Application → Cookies → fragment.com. Скопируй `stel_ssid`, `stel_dt`, `stel_token`, `stel_ton_token` в одну строку вида `stel_ssid=...; stel_dt=...; stel_token=...; stel_ton_token=...` и вставь в админке.
Если выдача остановилась с ошибкой про куки, вставь новые.

## Как работает

- **Монобанк.** Каждому заказу выдаётся своя сумма с копейками (например, 90,66 ₴). Раз в минуту, а с вебхуком сразу после перевода, бот смотрит выписку через API банка. Пришла ровно такая сумма — заказ оплачен. Переводы без заказа бот присылает тебе, и их можно подтвердить вручную в админке.
- **Карта РФ.** Покупатель переводит деньги и шлёт скрин боту. Скрин уходит проверяющему с кнопками ✅/❌. В админке «РФ» считается, сколько звёзд ушло по его оплатам: деньги получает он, а TON тратится твой.
- **Выдача** идёт по одному заказу. Бот покупает звёзды на Fragment, ждёт подтверждения транзакции в сети и пишет покупателю.
- **Защита:**
  - бот не купит дороже лимита «Макс. TON за 1 ★»;
  - если не хватает TON, выдача встаёт на паузу и тебе приходит сообщение;
  - неудачную транзакцию бот повторяет только после того, как у старой истёк срок действия, поэтому двойной отправки не будет;
  - проблемные заказы попадают в «⚠️ Проверка».

⚠️ С кошелька бота больше ничего не отправляй вручную. Бот следит за номером транзакции (seqno), и ручные переводы могут сбить выдачу.
